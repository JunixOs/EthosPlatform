# **Límites del Proyecto**

## 1. Funcionalidades Incluidas

El sistema permitirá:

- Autenticación, registro y gestión de perfiles de usuario.
- Creación, edición, eliminación, filtrado y búsqueda de experiencias.
- Respuestas (un nivel), reacciones, etiquetado y marcado de favoritos.
- Feed personalizado, secciones de contenido reciente y destacado.
- Panel de administración, gestión de usuarios, contenido y moderación.
- Página dedicada al equipo de desarrollo (editable solo por administradores).
- Modo claro/oscuro, diseño responsive, borradores automáticos.
- Seguridad con sesiones, cifrado y bloqueo por intentos fallidos.

## 2. Funcionalidades Excluidas

El sistema no permitirá:

- Mensajería privada en tiempo real
- Videollamadas
- Integración con redes sociales externas
- Aplicaciones móviles nativas
- Pagos 
- Múltiples idiomas
- Inteligencia artificial avanzada

## 3. Alcance de Primera Versión

**Versión 1 (MVP)**:

- Autenticación, registro y gestión de perfiles de usuario.
- Creación, edición, eliminación, filtrado y búsqueda de experiencias.

- Modo claro/oscuro, diseño responsive, borradores automáticos.
- Seguridad con sesiones, cifrado y bloqueo por intentos fallidos.

## 4. Futuras Versiones
